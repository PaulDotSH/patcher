# Bundled fonts

The default theme's fonts, embedded in the GUI stub. Built from trap.foarte.top's
Latin + Latin Extended woff2 subsets with fontTools: the variable fonts are pinned to one
weight and each font's two subsets merged into a single TTF.

| file | font | license |
|---|---|---|
| `anton.ttf` | Anton, The Anton Project Authors | SIL OFL 1.1, `OFL-anton.txt` |
| `inter-400.ttf`, `inter-600.ttf` | Inter, The Inter Project Authors | SIL OFL 1.1, `OFL-inter.txt` |
| `jetbrains-mono-500.ttf` | JetBrains Mono, The JetBrains Mono Project Authors | SIL OFL 1.1, `OFL-jetbrainsmono.txt` |

The license texts are embedded next to the fonts, as the OFL requires.
